# Lumen｜2035 Chat App

直接用 Edge 或 Chrome 開啟 index.html，不需安裝或連網。此版本修改自原本的 2035_chat_app.zip，保留主要五幕與訊息互動流程，另加入晚餐與尾聲拍攝場景。

## 逐幕拍攝
- 桌面右側選擇一幕；切換或「重設本幕」會清除該幕臨時操作，不會累積其他幕。
- 數字 1–5 切換場景（輸入文字時不觸發）；R 以目前預覽構圖切換錄影模式。
- 手機寬度下自動隱藏所有開發控制項。
- 直接指定網址參數：`?scene=first&record=portrait` 或 `?scene=reject&record=landscape&layout=right&bg=living`。場景名稱為 first、birthday、apology、reject、ending。
- 直式錄製建議瀏覽器設 390×844、縮放 100%；橫式錄製建議設 1920×1080 或其他 16:9 尺寸。若要滿框輸出，請在擷取軟體中只錄取 16:9 畫布區域。
- 右側「顯示已讀」可切換已讀／已送出（收到的訊息則顯示未讀）。這是拍攝用模擬狀態，無真實通訊後端。
- 第一幕請直接按 AI 建議「送出」；返回箭頭仍可用於另外拍攝鎖屏轉場。
- AI 卡片向上拖曳或觸控滑動超過 48px 可略過；也能點「略過」。
- AI 建議送出附「由助理建議」；手動文字不附標記。道歉送出自動依劇情分成三行。
- 結尾自行輸入「好，晚上打給妳。」並送出。
- 電話按鈕進入模擬撥號介面，顯示「媽❤️／林淑芬」，約 2 秒後切換為通話中並每秒計時。掛斷或返回聊天均保留本幕聊天狀態，沒有真正撥出電話。桌面控制面板的摺疊「通話秒數（拍攝用）」可設定起始秒數。
- 加號聚焦輸入框；更多選項提供關閉畫面。
- 所有資料僅存在本頁記憶體，重新整理會重設。時間固定於各幕，便於連戲。

## 原創與素材
本介面為學術競賽影片所製作之原創虛構聊天 App UI，不屬於 LINE 或任何現有通訊軟體，亦未使用其商標、Logo 或官方視覺素材。

全部圖示為本專案內嵌自製 SVG／文字；使用系統字體，無外部字型、品牌素材或網路依賴。聊天泡泡使用 #C4E6A6、無尾巴及非對稱圓角；AI 卡片採藍灰色，獨立於訊息區。

## 橫式錄影畫布
桌面開發面板可切換 Portrait Preview／Landscape Recording Preview、Center Phone／Right Phone，以及 Dark／Office Blur／Living Room Blur／Neutral Gradient。橫式畫布固定 16:9，手機聊天內頁維持 390×844 的原始排版，整支手機含外殼約佔畫布高度 89%。背景以 CSS 製作，沒有第三方照片或品牌素材。

- `?record=landscape`：開啟 16:9 橫式錄影畫布，隱藏開發工具。
- `?record=portrait`：開啟純手機直式錄影畫面，隱藏開發工具。
- `layout=center|right`、`bg=dark|office|living|neutral`：設定橫式構圖。
- `scene=first|birthday|apology|reject|ending`：指定單一劇情場景。

錄影模式仍可按數字 1–5 切換場景；按 R 可返回開發預覽。這些快捷鍵在文字輸入時不會觸發。

## 隱藏拍攝控制台
錄影與預覽畫面預設完全隱藏控制台。按 **Tab** 叫出控制台，按 **Esc** 或控制台右上角 × 隱藏。控制台中可切換主要五幕及晚餐／尾聲場景、預覽模式、手機位置與背景；每一幕的背景和手機位置會在同一個開啟的頁面內分別記住。控制台還有通話起始秒數與「重置電話秒數為 00:00」；通話中按重置會立即從 00:00 繼續計時，下一次撥號也從 0 秒開始。重新整理頁面後，各幕設定會回到預設。

## 自訂背景圖片
在錄影頁按 Tab 打開控制台，於「上傳這一幕的背景圖片」選擇本機圖片。圖片會填滿橫式畫布；下方滑桿可調整模糊程度（0–24px）。每幕可以上傳不同圖片，切幕時會恢復各自的圖片和模糊設定。「移除這一幕的圖片」只清除目前場景。圖片只在目前開啟的頁面中使用，不會上傳到伺服器；重新整理後需重新選取。

## 固定範圍截圖
在錄影頁按 Tab 打開拍攝控制台，先點「選擇『下載』資料夾」並在瀏覽器選取本機的 Downloads／下載。程式會在其中建立「後置畫面」資料夾。之後點「截取目前畫布 PNG」；首次截圖時，瀏覽器會請你選擇分享來源，請選 **目前分頁**。控制台會在擷取前隱藏。橫式每張固定 1920×1080，直式每張固定 390×844，裁切範圍只取畫布內側，不含畫布外的黑色留白。每張檔名包含場景、尺寸及時間，避免覆蓋。瀏覽器重新整理後需再選一次資料夾；若視窗大小改變，可能需要重新選擇目前分頁。此功能需要支援分頁擷取與資料夾選取的 Edge 或 Chrome。

## 畫布錄影
開啟錄影頁後按 Tab，先選擇本機「下載」資料夾。程式會在裡面建立「後置畫面」。按「開始錄製 MP4」後，首次使用請在瀏覽器選擇分享 **目前分頁**；控制台會自動隱藏，錄影只取畫布的固定範圍。按 **V** 停止並儲存到「下載／後置畫面」，也可按 Tab 開控制台再按「停止並儲存影片」。錄製中按 **B** 可切換手機黑屏，點黑屏可喚醒；按 Tab 打開控制台期間，輸出會暫停在上一張乾淨畫面，避免把控制台錄進影片。橫式固定 1920×1080，直式固定 390×844。最新版 Edge／Chrome 可直接輸出 MP4；若瀏覽器不支援 MP4，會使用 WebM。影片僅含畫面，不錄麥克風或系統聲音。

## 豆花照護報告與後製素材
`report.html?days=8&layout=center` 顯示可捲動的長報告；`days=3|4|5|6|7|8|0|1` 可切換正常天數，`variant=bottom` 開啟時直接定位在備註和本月紀錄。`days=1&greet=1` 顯示尾聲「今日已有人問候」。報告依新版正式拍攝劇本製作：用藥、飲食、生命徵象、跌倒風險，以及「兩人份／一人用餐／蛋糕未開封／本月 4 次」的關鍵資訊。聊天頁另有 `scene=dinner` 和 `scene=morning`。

依 10 月 26 日新版劇本與綠幕操作規格重錄的 1920×1080 素材位於「下載／後置畫面／新版劇本」。詳細檔名與剪輯用途見其中的 `新版素材對照表.md`。MP4 是無聲畫面素材；實拍人物、旁白和門鈴聲需在剪輯時合成。

## 白天／深夜辦公室與淑芬家背景
已內建拍攝提供的三張背景圖：`assets/office-day.png`、`assets/office-night.png`、`assets/home-room.jpg`。淑芬家原圖為 `IMG_8912.HEIC`，已轉成瀏覽器可顯示的 JPG。聊天頁、報告頁與 `shot.html` 支援 `bg=day-office|night-office|home-room`。時間卡與結尾字幕使用黑底。

## 修訂後的角色弧線
新版劇本中，第一幕「好棒，記得按時吃藥 ♡」直接送出後鎖手機；第四幕淑芬端輸入「妳」又刪掉，7 天通知被滑走；第五幕道歉仍由 AI 建議送出；第六幕報告分兩段揭露；第七幕關閉又重新打開報告，蛋糕建議被滑掉；尾聲「媽早安 ♡」未送出，雅婷直接打電話，正常天數為 1 天，最後親自輸入回診回覆。`shot.html?shot=order|draft|notice|family-detect|family-done` 提供新增的拍攝補充畫面。
